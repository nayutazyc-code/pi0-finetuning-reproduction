## 3. 怎样从失败训练到当前结果

| 阶段 | 实际执行与选择 | 结果 |
|---|---|---|
| 第一轮 `banana_pilot_v1` | 2,000 次更新，严格只训练 LoRA | 两次闭环均未抓起/入盒 |
| 第二轮 `banana_v2_phase4000` | 原计划 4,000；实际在中途评估后主动结束，使用保存的 **2000** 检查点继续 | 起始误差大幅降低，已能抓起，但仍有滑脱、定位偏差 |
| 第三轮 `banana_v3_roi2000` | 从第二轮 2000 权重继续 2,000 次更新；采用 ROI | 最终 **1999** + 完整动作块执行通过本次全部最终运行 |

第二轮主动结束退出码为 130，原因和选择记录已保存；未宣称它完成了原计划 4,000 步。首轮和中间所有失败视频、日志仍保留。

本次实际组合改进：

1. **训练采样。** 原始帧中闭爪/松爪约占 7.1%；新采样中合计约占 28.5%，另增加启动前 10 帧的采样概率。
2. **状态尺度。** ALOHA 适配后的 state 标准差下限设为 0.01，降低近常量维度对微小偏差的放大。动作统计保留训练数据实际尺度。
3. **可训练参数。** 在 LoRA 之外解冻 state/action 投影和动作时间 MLP，共约 5,324 万个可训练参数。
4. **任务加权。** 右夹爪的 Flow Matching 误差权重为 4，右臂关节为 1，左臂为 0.25，补齐维度为 0.1。
5. **视觉区域。** 用同一真实图像 ROI 提高香蕉、盒子与手指的视觉细节，训练和部署均从原始图像裁剪。
6. **执行连贯性。** 使用完整 50 步预测块，并将目标速度限制在覆盖本批专家动作速度的范围内。

这些修改共同完成了任务。没有进行完整单因素消融，无法把收益分别归因于每一项。

## 4. 现在在 Mac 怎样运行

本次已启动云端服务，并建立带压缩的 SSH 隧道。可直接在 Mac 终端执行：

```bash
cd '/path/to/pi0-repro'
bash scripts/run_mac.sh connect --config configs/banana_finetuned_pi0.toml
bash scripts/run_mac.sh run --config configs/banana_finetuned_pi0.toml
```

正式配置会显示相机画面，并保存视频。无窗口运行可使用本次的 `configs/banana_roi_chunk50_eval.local.toml`。

### SSH 隧道断开后

已有 8000 隧道时直接复用；断开后在 Mac 终端重新运行并保持打开：

```bash
SSH_PORT=2222  # 示例值，请替换为服务器的实际 SSH 端口。
ssh -C -i ~/.ssh/your_ssh_key -p "$SSH_PORT" \
  -o ExitOnForwardFailure=yes -N \
  -L 127.0.0.1:8000:127.0.0.1:8000 \
  user@your-server.example.com
```

`-C` 对原始相机图像启用 SSH 压缩，减少传输量。
